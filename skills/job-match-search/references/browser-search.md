# Visible browser search

세 MCP는 사용자가 볼 수 있는 별도 브라우저에서 공개 채용 검색을 수행합니다. 브라우저 자동화도 자동화이며 플랫폼의 허가나 법적 우회가 아닙니다.

## 실행 조건

- 사용자가 자신의 구직을 위한 개인·비상업용 검색이라고 확인했습니다.
- 플랫폼 최신 약관과 계정 제한 등 잔여 위험을 안내했고 사용자가 받아들였습니다.
- 상업용, 재판매, 팀 공유, 데이터셋, 학습 데이터와 예약 모니터링 목적이 아닙니다.
- 검색어에는 이력서 원문과 개인정보가 없습니다.

조건이 충족되지 않으면 search_jobs를 호출하지 않고 사용자가 제공한 개별 공고만 비교합니다.

## 실행 절차

1. get_search_options로 현재 스키마를 확인합니다.
2. 직무명, 대표 기술, 지역과 확실한 선호만 전달합니다.
3. acknowledgePersonalUse를 true로 설정하고 search_jobs를 한 번 호출합니다.
4. 열린 브라우저 화면과 반환된 provider, searchUrl, filters.applied, filters.skipped, resultCount와 results를 확인합니다. 미적용 조건은 추천의 미확인 범위에 명시합니다.
5. 플랫폼당 최대 20건을 넘지 않고 중복을 제거합니다.
6. 결과가 부족하면 사용자에게 검색어 조정 여부를 묻습니다. 다음 페이지를 자동 이동하지 않습니다.
7. CAPTCHA, 로그인, 비정상 접근, 403·429 또는 차단 안내가 나타나면 즉시 중단합니다.

## 데이터 경계

MCP는 새 비영구 브라우저 컨텍스트를 사용합니다. 기존 브라우저 프로필, 디버깅 포트, 쿠키와 비밀번호에 연결하지 않습니다. 현재 화면에서 실제 표시되는 공고 링크, 제목과 최대 600자의 카드 문맥만 메모리에서 처리합니다.

원문, HTML, 내장 JSON, 네트워크 요청, 쿠키, 세션과 결과 데이터베이스를 저장하지 않습니다. 숨겨진 API, User-Agent 위장, 접근 제한 우회, 무한 스크롤과 상세 페이지 묶음 탐색을 사용하지 않습니다.

## 사용자 안내 요약

검색 전에 다음 의미를 전달합니다.

- 이 기능은 개인·비상업용 단일 검색으로 제한됩니다.
- 브라우저 자동화에도 약관·법률·계정 제한 위험이 남습니다.
- 프로젝트는 플랫폼 허가 또는 법률 자문을 제공하지 않습니다.
- 사용자는 최신 약관과 결과 이용 방식에 책임을 집니다.
- 면책 고지는 법률상 배제할 수 없는 책임까지 면제하지 않습니다.

자세한 근거는 저장소 루트 COMPLIANCE.md를 따릅니다.
