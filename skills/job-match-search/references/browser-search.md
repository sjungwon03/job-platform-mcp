# 개인용 브라우저 검색

이 모드는 공식 API가 연결되지 않은 개인 사용자가 자신의 화면에 표시되는 Wanted·사람인·잡코리아 검색 결과를 탐색하도록 돕는다. 법적 제한을 우회하는 기능이나 크롤링 허가가 아니며, 브라우저를 사용한다는 사실만으로 자동화가 비자동화로 바뀌지 않는다.

## 사용 조건

다음을 모두 만족할 때만 사용한다.

- 사용자가 자신의 구직을 위한 개인·비상업용 검색이라고 확인했다.
- 결과를 외부 서비스, 팀 데이터베이스, 학습 데이터나 판매 상품으로 축적·재배포하지 않는다.
- 사용자가 요청한 검색 한 번만 실행하고 백그라운드, 예약 또는 반복 모니터링을 하지 않는다.
- 로그인, CAPTCHA, robots.txt, 속도 제한, 403·429 응답, IP 차단이나 기타 접근 제한을 우회하지 않는다.
- 이력서 원문과 개인정보를 플랫폼 검색어, URL 또는 폼에 입력하지 않는다.

조건이 충족되지 않거나 사용 목적이 불명확하면 공식 API 또는 사용자가 제공한 개별 공고만 사용한다.

## 검색 프로필

현재 대화에서 다음 최소 조건만 유지한다.

- 목표 직무와 직무 동의어
- 실제 사용 기술 중 검색에 필요한 핵심 기술
- 희망 지역 또는 지역 무관
- 경력 범위
- 고용 형태와 원격·하이브리드 선호
- 사용자가 명시한 필수·제외 조건

사용자가 별도 저장을 요청하지 않으면 세션 밖에 저장하지 않는다. 저장을 요청해도 연락처, 주소, 생년월일, 이력서 원문은 검색 프로필에 넣지 않는다.

## 실행

에이전트에 화면이 보이는 브라우저 자동화 기능이 있으면 이를 우선 사용한다. 개인 브라우저의 디버깅 포트에 연결하거나 기존 프로필의 쿠키·비밀번호를 추출하지 않는다.

브라우저 도구가 없으면 아래 스크립트로 검색 URL을 확인하거나 기본 브라우저에서 연다.

~~~bash
node skills/job-match-search/scripts/browser-search.mjs \
  --provider wanted,saramin,jobkorea \
  --query "백엔드 Java 서울"
~~~

URL만 출력하는 것이 기본값이다. 사용자가 책임 고지를 받아들이고 브라우저 검색을 요청한 경우에만 --open과 --acknowledge-personal-use를 함께 추가한다.

~~~bash
node skills/job-match-search/scripts/browser-search.mjs \
  --provider wanted,saramin,jobkorea \
  --query "백엔드 Java 서울" \
  --open --acknowledge-personal-use
~~~

스크립트는 허용 목록에 있는 공식 검색 URL만 생성하며 임의 URL을 받지 않는다. URL을 연 뒤에는 다음 순서를 따른다.

1. 사용자가 요청한 지역·경력·고용 형태를 화면의 공식 필터로 적용한다.
2. 현재 화면에 표시된 공고 중 최대 20건만 읽는다.
3. 제목, 회사, 지역, 마감일, 최소한의 요약과 원문 링크만 사용한다.
4. 상세 내용은 적합 후보 또는 사용자가 선택한 공고만 연다.
5. 다음 페이지는 사용자가 더 찾아달라고 명시적으로 요청한 경우 한 페이지만 이동한다.
6. 결과 원문, HTML, 쿠키 또는 세션을 파일이나 데이터베이스에 저장하지 않는다.
7. 403, 429, CAPTCHA, 비정상 트래픽 안내가 나타나면 해당 플랫폼 자동화를 즉시 중단한다.

숨겨진 내부 API, 페이지 소스의 내장 JSON, 네트워크 요청 복제, 브라우저 위장 헤더와 병렬 탭 대량 탐색은 사용하지 않는다.

## 책임과 고지

검색을 시작하기 전에 다음 의미를 사용자에게 간단히 알린다.

- 플랫폼 약관과 관련 법령을 확인하고 기능 사용 여부를 결정할 책임은 사용자에게 있다.
- 이 프로젝트는 법률 자문이나 플랫폼의 이용허락을 제공하지 않는다.
- 브라우저 자동화는 계정 제한, IP 차단, 결과 오류 또는 약관 분쟁 위험을 완전히 제거하지 않는다.
- 관련 법령이 허용하는 최대 범위에서 제작자와 기여자는 사용자의 실행 방식, 수집·저장·재배포 및 그 결과에 대한 책임을 부담하지 않는다.
- 고의·중과실 등 법률상 배제할 수 없는 책임까지 면제된다는 뜻은 아니다.

사용자가 이 조건을 받아들이지 않으면 브라우저 검색을 실행하지 않고 공식 API 또는 사용자 제공 공고 모드로 돌아간다.

## 판단 근거

- 저작권법 제30조는 비영리 개인 이용을 위한 복제를 정하지만, 반복적·체계적 데이터베이스 복제와 약관·접근 제한 문제는 별도로 판단될 수 있다.
- Wanted 개인회원 약관은 회사의 사전 허락 없는 자동화 수단을 통한 게시물 수집을 제한한다. Wanted 자체 검색 에이전트의 제공은 제3자 자동화 허락을 의미하지 않는다.
- 저작권법 제93조는 데이터베이스의 상당 부분 및 통상 이용과 충돌하는 반복적·체계적 복제를 보호 대상으로 정한다.
- RFC 9309는 브라우저를 콘텐츠를 표시하는 클라이언트로, crawler를 자동화된 클라이언트로 구분하며 robots.txt가 접근 권한 자체는 아니라고 명시한다.
- 사람인 개인회원 약관은 서비스를 통해 얻은 정보의 무단 복사·복제·사용을 제한한다.
- 잡코리아 robots.txt는 일부 공개 경로를 허용하지만 검색 URL 일부를 제한한다.
