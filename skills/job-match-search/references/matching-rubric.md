# Matching rubric

공고별 적합도는 100점 척도로 비교하되, 각 점수에 사용자 자료와 공고의 근거를 연결한다.

| 항목 | 배점 | 판단 기준 |
| --- | ---: | --- |
| 직무·책임 일치 | 25 | 수행한 업무와 공고의 핵심 책임이 실제로 겹치는가 |
| 필수 기술 일치 | 25 | 필수 기술의 사용 경험과 프로젝트 근거가 있는가 |
| 경력·직급 일치 | 15 | 요구 연차와 책임 수준에 부합하는가 |
| 도메인 일치 | 10 | 산업 또는 문제 영역 경험이 직접 관련되는가 |
| 근무 조건 일치 | 10 | 지역, 원격, 고용 형태, 비자 같은 조건이 맞는가 |
| 선호 조건 일치 | 10 | 사용자가 명시한 역할 방향, 조직·제품 선호에 맞는가 |
| 정보 신뢰도 | 5 | 원문 링크, 최신성, 요구사항과 마감일을 확인했는가 |

## 판정

- 85~100: 매우 높은 적합도
- 70~84: 높은 적합도
- 55~69: 검토 가치 있음
- 0~54: 낮은 적합도

점수 구간은 정렬용 휴리스틱이며 합격 확률이 아니다.

## 필수 조건

사용자가 명시한 절대 조건을 위반하면 점수와 별개로 조건 불일치로 분리한다. 예:

- 근무 불가능한 지역 또는 출근 방식
- 요구 경력이 사용자 경력과 현저히 다른 경우
- 사용자가 제외한 고용 형태
- 필수 비자·언어·자격 요건을 충족하지 못한다는 명확한 근거

공고 정보가 없다는 이유만으로 불충족으로 단정하지 않는다. 미확인은 점수를 과도하게 깎지 말고 정보 신뢰도와 격차 칸에 반영한다.

## 근거 규칙

- 확인: 사용자 자료와 공고 양쪽에 직접 근거가 있음
- 추정: 인접 경험으로 가능성이 있지만 직접 근거가 부족함
- 미확인: 어느 한쪽 정보가 없음
- 불일치: 양쪽 정보가 명확히 충돌함

같은 단어의 출현 횟수보다 수행 맥락과 성과를 우선한다. 예를 들어 기술명이 나열만 되어 있으면 프로젝트에서 사용한 기술보다 낮은 확신으로 평가한다.
